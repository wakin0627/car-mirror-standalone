# CarWith Browser Bridge

This project relays Xiaomi CarWith video, audio and touchscreen input between a phone and a vehicle browser on the same Wi-Fi network. Version 1.0.0 is the first maintained baseline of this repository.

See [Browser Bridge](BROWSER_BRIDGE.md) for installation, setup and build details. Xiaomi CarWith and the compatible Xiaomi CarLife component must already be installed on the phone. Actual size, frame rate, touch, audio and background operation depend on the phone and vehicle browser.

# CarWith 网页桥接

本项目将手机上的小米 CarWith 画面、声音和触控桥接到同一 Wi-Fi 下的车机浏览器。1.0.0 是本仓库的首个维护版本。

安装、设置和构建方法见 [网页桥接说明](BROWSER_BRIDGE.md)。手机需预先安装兼容的小米 CarWith 和小米 CarLife 组件。实际画面尺寸、帧率、触控、声音和后台运行效果取决于手机和车机浏览器。

本项目派生自 [mcarplay](https://github.com/wangxso/mcarplay)，许可和第三方声明见 [LICENSE](LICENSE)、[NOTICE](NOTICE) 和 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
